# SSH Port Forwarder

一个面向 Windows 的可视化 SSH 端口转发工具。它用桌面界面管理 `ssh.exe` 隧道，让常用连接可以保存、复用、连接、断开和自动重连。

## 主要功能

- 保存历史连接，并支持配置、删除和复用。
- 支持 Local、Remote、Dynamic SOCKS 三种 SSH 转发模式。
- 支持连接、断开、全部断开和保持连接自动重连。
- 支持一次性密码连接，密码不会写入历史配置。
- 支持一键上传 SSH 公钥到远程主机，快速配置免密登录。
- 保存前自动校验 SSH 配置参数，减少无效连接。
- 内置使用向导页面，帮助第一次使用时快速上手。
- 支持 Debug、Info、Warning、Error 日志等级。
- 支持 dark / light 主题和中文 / 英文界面。
- 应用退出时自动清理由它启动的 SSH 转发进程。
- 连接进程在后台运行，不额外弹出终端窗口。

## 下载与运行

从 GitHub Releases 下载 `v0.1.1`：

- 推荐下载安装包：`SSH Port Forwarder_0.1.1_x64-setup.exe`
- 也可以直接运行免安装程序：`ssh-port-forwarder.exe`

运行前请确认 Windows 已安装 OpenSSH Client，并且 PowerShell 中可以执行：

```powershell
ssh -V
```

## 快速上手

1. 打开程序后默认进入“历史连接 / 连接管理”页面。
2. 点击“新建”，填写 SSH 主机、用户、端口和转发参数。
3. 点击“连接”，程序会保存配置、关闭弹窗并回到主页面。
4. 在主页面查看连接状态和运行日志。
5. 点击同一条连接可以选中，再点一次可以取消选中。

## 常用样例

如果远程服务器上有一个服务只监听 `127.0.0.1:8000`，你希望在本地浏览器打开它：

| 字段 | 填写 |
| --- | --- |
| 模式 | `local` |
| SSH 主机 | 服务器 IP 或域名 |
| SSH 端口 | `22` |
| SSH 用户 | `root` / `ubuntu` / `deploy` |
| 监听地址 | `127.0.0.1` |
| 监听端口 | `8000` |
| 目标地址 | `127.0.0.1` |
| 目标端口 | `8000` |

连接成功后，在本地浏览器访问：

```text
http://127.0.0.1:8000
```

等价命令大致是：

```powershell
ssh -N -T -L 127.0.0.1:8000:127.0.0.1:8000 用户名@服务器地址 -p 22
```

## 转发模式怎么选

| 模式 | 适用场景 |
| --- | --- |
| Local | 把本地端口转发到远程服务器能访问到的服务。最常用，适合远程数据库、远程 Web 服务。 |
| Remote | 把远程端口反向转发到本机服务。适合临时暴露本地开发服务。 |
| Dynamic | 创建 SOCKS 代理。通常只需要监听地址和监听端口。 |

## 密码与密钥

推荐优先使用 SSH 密钥或 `ssh-agent`。

如果还没有配置免密登录，可以在连接上点击“上传公钥”，输入一次密码后，程序会把本地公钥写入远程主机的 `authorized_keys`，之后即可免密连接。

如果需要密码登录，可以点击“一次性密码连接”：

- 密码不会保存到历史连接配置。
- 如果开启“保持连接”，密码只会在本次应用运行期间保留在内存中，用于异常断开后的自动重连。
- 如果是第一次连接某台服务器，请先在 PowerShell 手动执行一次 `ssh 用户@主机 -p 端口`，确认主机指纹后再回到程序连接。

## 数据保存位置

连接历史、设置和日志保存在 Windows 应用数据目录中，不会保存在源码目录或程序所在目录。
